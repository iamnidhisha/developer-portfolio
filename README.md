# Developer Portfolio

A modern, responsive developer portfolio built with React, Vite, TypeScript, Tailwind CSS, and Motion.

**Live Website:** (https://nidhi-developer-portfolio.netlify.app/)

## Tech Stack

- React
- Vite
- TypeScript
- Tailwind CSS
- Motion for React
- Lucide React

## Features

- Premium dark-themed UI
- Fully responsive layout
- Smooth scroll navigation
- Animated hero and section reveals
- Interactive project showcase
- Skills, services, experience, and contact sections
- Client-side contact form validation
- SEO-friendly metadata

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.

## Build for Production

```bash
npm run build
npm run preview
```

## Deployment

This project is deployed on Netlify.

- Build command: `npm run build`
- Publish directory: `dist`
